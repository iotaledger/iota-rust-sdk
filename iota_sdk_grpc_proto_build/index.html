Proto build tool for generating gRPC types with field constants.

Everything is written into iota-sdk-grpc-types/src/proto/generated and committed, so a run that changes the output fails the build. The pipeline is:

  1. discover_proto_files — collect the .proto sources in a stable order.
  2. compile_proto_files — compile them with protox into a descriptor pool (name resolution, options) and a file descriptor set.
  3. generate_tonic — prost/tonic structs, clients and servers.
  4. add_license_headers — license headers and super::google rewrites on the files prost just wrote.
  5. Accessor generation — with_/set_/getter methods driven by the iota.grpc.*_accessors proto options.
  6. Service method paths, then field constants and MessageFields impls, which together back read masks and field path builders.
  7. verify_generated_files_committed — fail if the output drifted from what is committed.
