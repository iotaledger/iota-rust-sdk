Removes Eq and Hash from the derive list of each given message.

See STRIP_EQ_HASH_MESSAGES for why. Each message is resolved through the descriptor pool to its own generated file (<package>.rs) and struct name, so a name shared by another package cannot be matched by mistake. Within that file the derive directly above the struct is rewritten: Eq and Hash are dropped and every other derive is kept, whatever the set or order. A message that no longer derives them (for example once it gains a non-hashable field) is left unchanged. The struct must appear exactly once in the file, so a nested type sharing the name fails the build rather than having the wrong struct stripped.
