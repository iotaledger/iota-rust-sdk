The single context over the compiled protobuf descriptors.

protox produces a [DescriptorPool] that already resolves names, nesting, map entries and options across files, so this type adds only what the pool cannot know: where a message lands in the generated Rust module tree, which version module a package belongs to, and which messages reference each other in a cycle.

Protobuf names come in two shapes: the pool uses bare names (iota.grpc.v1.types.Digest), while FieldDescriptorProto::type_name and the boxing config carry a leading dot. Everything here accepts either and normalizes on the way in.
