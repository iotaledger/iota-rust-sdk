pub(crate) fn has_reference_cycle(&self, from: &str, to: &str) -> bool

True when to reaches back to from through message-typed fields, i.e. the two sit on a reference cycle. Used to stop MessageFields::FIELDS from recursing forever.

The walk is scoped to the package from belongs to: cycle breaking has always been decided per package, and a path leaving the package cannot close a cycle the generated code would recurse through.
