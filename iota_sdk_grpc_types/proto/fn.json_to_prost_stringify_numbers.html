Converts a serde_json::Value to a prost_types::Value, rendering every number as a string.

google.protobuf.Value carries every number as an f64, which cannot hold every integer exactly. All numeric values go as strings for the receiver to parse against the type it expects. This applies at every depth, so a number nested in an array or object becomes a string too.

Numeric values not representable by serde_json::Number, eg. a Move u128/u256 argument, must be passed as serde_json::Value::String directly.
