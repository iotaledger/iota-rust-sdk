Trait IntoReadMask 

Source 
pub trait IntoReadMask<M> {
    // Required method
    fn into_read_mask(self) -> M;
}
Expand description

Conversion into an endpoint-scoped read mask.

This is the bound used by the client’s read_mask parameters. It is implemented for everything convertible into the endpoint’s mask type: the mask itself (e.g. ObjectReadMask::default() for the endpoint default), a field constant of the matching field namespace (e.g. ObjectField::BCS), arrays/slices/Vecs of such fields, and raw &'static str/String field paths.
