4/// Summary of gas charges.
5///
6/// Storage is charged independently of computation.
7/// There are 3 parts to the storage charges:
8/// - `storage_cost`: it is the charge of storage at the time the transaction is
9///   executed. The cost of storage is the number of bytes of the objects being
10///   mutated multiplied by a variable storage cost per byte
11/// - `storage_rebate`: this is the amount a user gets back when manipulating an
12///   object. The `storage_rebate` is the `storage_cost` for an object minus
13///   fees.
14/// - `non_refundable_storage_fee`: not all the value of the object storage cost
15///   is given back to user and there is a small fraction that is kept by the
16///   system. This value tracks that charge.
17///
18/// When looking at a gas cost summary the amount charged to the user is
19/// `computation_cost + storage_cost - storage_rebate`
20/// and that is the amount that is deducted from the gas coins.
21/// `non_refundable_storage_fee` is collected from the objects being
22/// mutated/deleted and it is tracked by the system in storage funds.
23///
24/// Objects deleted, including the older versions of objects mutated, have the
25/// storage field on the objects added up to a pool of "potential rebate". This
26/// rebate then is reduced by the "nonrefundable rate" such that:
27/// `potential_rebate(storage cost of deleted/mutated objects) =
28/// storage_rebate + non_refundable_storage_fee`
29///
30/// # BCS
31///
32/// The BCS serialized form for this type is defined by the following ABNF:
33///
34/// ```text
35/// gas-cost-summary = u64 ; computation-cost
36///                    u64 ; storage-cost
37///                    u64 ; storage-rebate
38///                    u64 ; non-refundable-storage-fee
39/// ```
40#[derive(Clone, uniffi::Record)]
41pub struct GasCostSummary {
42    /// Cost of computation/execution
43    pub computation_cost: u64,
44    /// The burned component of the computation/execution costs
45    pub computation_cost_burned: u64,
46    /// Storage cost, it's the sum of all storage cost for all objects created
47    /// or mutated.
48    pub storage_cost: u64,
49    /// The amount of storage cost refunded to the user for all objects deleted
50    /// or mutated in the transaction.
51    pub storage_rebate: u64,
52    /// The fee for the rebate. The portion of the storage rebate kept by the
53    /// system.
54    pub non_refundable_storage_fee: u64,
55}
