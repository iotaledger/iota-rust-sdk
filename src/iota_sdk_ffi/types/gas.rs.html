4/// Summary of gas charges.
5///
6/// Storage is charged independently of computation.
7/// There are 3 parts to the storage charges:
8/// - `storage_cost`: it is the charge of storage at the time the transaction is executed. The cost
9///   of storage is the number of bytes of the objects being mutated multiplied by a variable
10///   storage cost per byte
11/// - `storage_rebate`: this is the amount a user gets back when manipulating an object. The
12///   `storage_rebate` is the `storage_cost` for an object minus fees.
13/// - `non_refundable_storage_fee`: not all the value of the object storage cost is given back to
14///   user and there is a small fraction that is kept by the system. This value tracks that charge.
15///
16/// When looking at a gas cost summary the amount charged to the user is `computation_cost +
17/// storage_cost - storage_rebate` and that is the amount that is deducted from the gas coins.
18/// `non_refundable_storage_fee` is collected from the objects being mutated/deleted and it is
19/// tracked by the system in storage funds.
20///
21/// Objects deleted, including the older versions of objects mutated, have the storage field on the
22/// objects added up to a pool of "potential rebate". This rebate then is reduced by the
23/// "nonrefundable rate" such that: `potential_rebate(storage cost of deleted/mutated objects) =
24/// storage_rebate + non_refundable_storage_fee`
25///
26/// # BCS
27///
28/// The BCS serialized form of this type is specified in
29/// [`bcs-schema.abnf`](https://github.com/iotaledger/iota-rust-sdk/blob/develop/crates/iota-sdk-types/bcs-schema.abnf).
30#[derive(Clone, uniffi::Record)]
31pub struct GasCostSummary {
32    /// Cost of computation/execution
33    pub computation_cost: u64,
34    /// The burned component of the computation/execution costs
35    pub computation_cost_burned: u64,
36    /// Storage cost, it's the sum of all storage cost for all objects created or mutated.
37    pub storage_cost: u64,
38    /// The amount of storage cost refunded to the user for all objects deleted or mutated in the
39    /// transaction.
40    pub storage_rebate: u64,
41    /// The fee for the rebate. The portion of the storage rebate kept by the system.
42    pub non_refundable_storage_fee: u64,
43}
