IntentMessage
Intent Message is a wrapper around a message with its intent. The message can be any type that implements [trait Serialize]. ALL signatures in IOTA must commit to the intent message, not the message itself. This guarantees any intent message signed in the system cannot collide with another since they are domain separated by intent.
