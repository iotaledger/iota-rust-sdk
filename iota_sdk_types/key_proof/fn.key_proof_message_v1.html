Expand description

Returns the text a key holder signs to approve attaching their key to a SmartAccount. The signature is over the UTF-8 bytes of the text, as an IOTA personal message.

  • chain_identifier: the digest of the genesis checkpoint, as gRPC’s ResponseExt::chain_id() returns it.
  • account: the account the key is attached to, or the transaction sender when new_account is true.
  • new_account: whether the account is new.
  • nonce: the nonce of the transaction that attaches the key.
  • valid_until_epoch: the last epoch in which the proof is valid.

Validators compute the same text to check the proof, so the result for given values must never change. A new text is a new function.
