Expand description

A link to a Ledger device that exchanges APDUs.

The crate provides transports for USB HID (behind the hid feature) and the Speculos emulator (behind the speculos feature); implement this trait to talk to the device over another link.

Provided Methods§

Source

fn reconnect(&mut self) -> TransportFuture<'_, ()>

Re-establish the link after the device switched apps, which closes the previous connection on some transports.

While waiting for an app to start, Ledger calls this at intervals until the app answers.

Source

fn can_switch_apps(&self) -> bool

Whether the device behind this transport can open and close apps.

Return false for emulators such as Speculos, which run a single app and report a placeholder app name unless configured otherwise.
