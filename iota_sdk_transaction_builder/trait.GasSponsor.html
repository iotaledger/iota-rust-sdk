Expand description

A service that pays the gas for someone else’s transaction.

A sponsor hands out gas against a budget and later executes the transaction that spends it, so it both funds and submits. Implement this to sponsor through a service the SDK does not ship; for the IOTA gas station, use GasStation.

Pass an implementation to execute_with_gas_sponsor.

The transaction pays with the SponsoredGas that reservation returned, and signature is the sender’s; the sponsor supplies its own.
