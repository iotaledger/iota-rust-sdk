# IOTA Move DeFi Starter Kit - 技术架构

## 概述

IOTA Move DeFi Starter Kit 是一个基于Sui Move区块链的DeFi协议示例实现，旨在展示如何在Sui上构建去中心化金融应用，并为IOTA生态系统提供可扩展的DeFi基础设施。

## 模块设计

### 1. 借贷池模块 (`lending_pool`)

#### 核心功能
- **资产供应和抵押**: 用户存入资产作为抵押品
- **借贷和还款**: 基于抵押品价值的借贷功能
- **利率模型**: 动态利用率调整的利率计算
- **健康因子监控**: 实时计算用户仓位风险

#### 数据结构
```move
struct PoolConfig {
    // 池配置参数
}

struct PoolState {
    // 池状态信息
}

struct UserPosition {
    // 用户仓位信息
}

struct InterestRateModel {
    // 利率模型参数
}
```

### 2. 闪电贷模块 (`flash_loan`)

#### 核心功能
- **单交易借贷**: 在同一交易中完成借、用、还
- **手续费机制**: 0.09%的标准手续费
- **原子性保证**: 交易失败则所有操作回滚
- **记录跟踪**: 完整的借贷记录和状态管理

### 3. 预言机集成模块 (`oracle_integration`)

#### 核心功能
- **多数据源支持**: Switchboard + Pyth双预言机
- **价格聚合**: 加权平均价格计算
- **数据验证**: 时效性和置信区间检查
- **配置管理**: 灵活的预言机配置

### 4. 清算模块 (`liquidation`)

#### 核心功能
- **健康因子监控**: 实时计算所有仓位风险
- **自动清算**: 抵押不足仓位的自动清算
- **奖励机制**: 清算奖金和惩罚机制
- **批量处理**: 高效的批量监控和清算

## 技术栈

### 区块链层
- **Sui Move**: 智能合约开发语言
- **Sui Framework**: 标准库和工具
- **Sui Testnet**: 测试网络环境

### SDK层
- **Rust SDK**: 主要开发语言，提供完整功能
- **多语言绑定**: Go, Python, Swift, Kotlin, C#
- **Web3.js**: JavaScript/TypeScript支持

### 工具链
- **Rust工具链**: 编译和测试
- **Docker**: 容器化开发环境
- **GitHub Actions**: CI/CD流水线

## 数据流

### 典型交易流程
1. **用户操作**: 通过SDK发起交易请求
2. **SDK处理**: 构造Move调用和参数
3. **合约执行**: Sui Move VM执行智能合约
4. **状态更新**: 区块链状态持久化
5. **事件发射**: 合约事件通知
6. **监控响应**: SDK监听和处理事件

### 价格更新流程
1. **预言机推送**: 外部预言机更新价格
2. **价格验证**: 合约验证价格有效性和时效性
3. **状态更新**: 更新合约内价格状态
4. **事件通知**: 发射价格更新事件
5. **监控响应**: 应用响应价格变化
