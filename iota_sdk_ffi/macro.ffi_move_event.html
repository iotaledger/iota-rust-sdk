Expand description

Define the FFI wrapper for a Move event mirror: the uniffi::Object newtype plus a try_from_bcs constructor. Events are not objects (no key ability, no UID), so there is no try_from_object and no id; they are decoded from the BCS contents of an event query result. Type-specific field accessors go in the trailing block and are spliced into the exported impl.
