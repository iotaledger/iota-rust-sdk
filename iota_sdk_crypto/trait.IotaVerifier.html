Expand description

Interface for verifying user transactions and messages in IOTA

§Note

This trait is implemented by the verifier and verifying key types of this crate as well as directly by the public key types of iota-sdk-types. The public key implementations validate the key bytes on every call, so when verifying many signatures with the same key it is cheaper to construct the corresponding verifying key once and verify with that instead.
