Available on crate feature serde only.
Expand description

A Rust mirror of a Move object that can be decoded from an Object.

struct_tag is the type of the objects it decodes, e.g. 0x2::coin::Coin<0x2::iota::IOTA> for Coin<IOTA>. Every MoveObject is also a MoveType with that same tag.

fn struct_tag() -> StructTag

The Move struct tag of the objects this type mirrors.
